Node.js 24 LTS supplies HTTP, cryptography, worker threads, compression and SQLite. Install it from an official or company-approved source. No third-party runtime npm dependencies are required.

DM Sans is distributed under the SIL Open Font License. See SalesDashboard/static/fonts/OFL-DM-Sans.txt. The offline template embeds the font for portable use. Othoba logos were retained from the supplied dashboard assets.

IIS, URL Rewrite, ARR, Nginx, systemd and launchd are separately installed hosting components. This ZIP supplies examples and instructions, not copies of those server products.

The bilingual Word guide uses DM Sans and Noto Sans Bengali for rendering. Fonts should be present on the computer opening the guide for matching layout; the source Markdown is also included.
